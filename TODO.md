# Дальнейшая проверка

Исправления аудита F01–F33 описаны в `docs/AUDIT_REMEDIATION.md`; проверка установки — в `implementation_checklist.md`.

Перед эксплуатацией остаётся выполнить проверки окружения на целевом Debian: TLS/DNS/UFW/fail2ban, восстановление резервной копии с файлами, длительные передачи через Caddy и контроль заполнения отдельного тестового диска. Они не могут быть подтверждены тестами исходного кода.

Опциональная возможность ТЗ: проверка присланного SHA-256. По умолчанию checksum не используется. Автоматический импорт неизвестных дорефакторинговых схем не выполняется: миграция останавливается без удаления данных, импорт проектируется на копии соответствующей схемы.
